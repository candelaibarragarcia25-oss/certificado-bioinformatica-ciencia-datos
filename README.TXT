README.TXT

descripcion 
este programa busca una secuencia de ADN (CTACAGAGAAATC) en todos los archivos .fasta

funcionamiento 
recorre todos los archivos fasta, busca la secuencia indicada con grep, muestra una linea anterior a la coincidencia y por ultimo guarda los resultados 
ultimo guarda los resultados en resultados.txt 

ejecucion 
para ejecutar el programa bash script_p2.sh

objetivo 
practicar el uso de comandos bash para buscar secuencias de ADN en archivos FASTA
